Sobre o Aplicativo

Este aplicativo foi desenvolvido como parte de um trabalho acadêmico, com o objetivo de aplicar conceitos práticos de desenvolvimento mobile utilizando Angular, Ionic e Firebase.

A proposta é demonstrar a integração entre tecnologias modernas de frontend, autenticação segura e persistência de dados em tempo real.

Este app não possui fins comerciais e foi criado exclusivamente para fins educacionais.
